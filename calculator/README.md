# Калькулятор

Простий Maven-проєкт на Java. Програма запитує два числа та операцію, показує результат або повідомлення про помилку й завершується. У Java-коді немає коментарів.

Потрібні IntelliJ IDEA та JDK 17 або новіший. Використовується вбудований Maven. Для першого завантаження JUnit потрібен інтернет.

## Запуск в IntelliJ IDEA

1. Розпакуй архів.
2. Відкрий кореневий `Калькулятор/pom.xml` через File → Open як Maven-проєкт.
3. У File → Project Structure → Project SDK вибери JDK 17 або 21.
4. Дочекайся завантаження залежностей Maven.
5. Відкрий `src/main/java/ua/study/calculator/Main.java` та запусти метод `main` зеленою кнопкою.
6. По черзі введи перше число, друге число та знак операції. Після кожного введення натискай Enter.

Для запуску тестів у вікні Maven вибери Lifecycle → test.

## Приклади введення

Кожне значення вводиться в окремому рядку.

| Перше число | Друге число | Операція | Очікуваний результат |
| --- | --- | --- | --- |
| `12.5` | `2.5` | `+` | `15.0` |
| `2` | `5` | `-` | `-3.0` |
| `-2` | `3` | `*` | `-6.0` |
| `5` | `2` | `/` | `2.5` |
| `5` | `0` | `/` | Повідомлення про ділення на нуль |
| `hello` | — | — | Повідомлення про неправильне число |
| `NaN` | `2` | `+` | Повідомлення про недопустиме значення |
| `Infinity` | `2` | `*` | Повідомлення про недопустиме значення |
| `2` | `3` | `%` | Повідомлення про невідому операцію |

У десяткових числах можна використовувати крапку або кому. Від'ємні числа та нуль дозволені, крім нуля в дільнику. Спеціальні значення `NaN` та `Infinity` не допускаються.

Для кожного запиту в кінці виводиться `Обробку запиту завершено.` — це робота блоку `finally`.

## Файли та пояснення для захисту

| Файл | Призначення |
| --- | --- |
| `Calculator.java` | Чотири методи: `add`, `subtract`, `multiply`, `divide`. Кожен приймає два `double` та повертає `double`. |
| `InvalidInputException.java` | Власний перевірюваний виняток, який наслідує `Exception`. |
| `Main.java` | Введення даних, вибір операції та блоки `try-catch-finally`. |
| `CalculatorTest.java` | Перевірки арифметики, ділення на нуль, `NaN` і нескінченності. |
| `MainTest.java` | Перевірки перетворення тексту на число: крапка, кома, неправильний текст і порожній рядок. |

`validate()` перевіряє обидва аргументи перед кожною операцією. `Double.isFinite()` повертає `false` для `NaN` та нескінченності. У такому випадку метод викидає `InvalidInputException`.

У `divide()` окремо перевіряється дільник. Для типу `double` Java сама не викидає `ArithmeticException` при діленні на нуль, тому ця перевірка написана явно через `throw new ArithmeticException(...)`.

Метод `parseNumber()` перетворює текст на число. Якщо `Double.parseDouble()` не може розібрати введення, він викидає `NumberFormatException`. Ця помилка перетворюється на власний `InvalidInputException` зі зрозумілим повідомленням.

`throws InvalidInputException` у заголовку методу попереджає про можливий перевірюваний виняток. `throw` безпосередньо викидає виняток. `catch` перехоплює його, а `finally` виконує завершальні дії після успішного обчислення або обробленої помилки.

У тестах `assertEquals()` перевіряє результат обчислення, а `assertThrows()` — очікуваний тип винятку. Малий допуск у порівняннях потрібний через особливості зберігання дробових чисел у `double`.

Перевірено збірку на JDK 17, проходження всіх 12 тестів і 13 консольних сценаріїв. У кожному сценарії повідомлення з `finally` виводиться один раз.
